# Easy Code Backup for VSCode!

Easy Code Backup is an extension that lets you save your project to Google Drive, Microsoft Onedrive, or Dropbox, without using Git.

## How to use

1. Open your VSCode editor.
2. Open the command palette (`Ctrl+Shift+P` or `Cmd+Shift+P`).
3. Run a command:  
    Run the _Easy Code Backup: Backup to `chosen file service`_ command to save your changes at a timestamp.  
    Run the _Easy Code Backup: Restore from `chosen file service`_ command to pull your changes from a specific time.
